# Project logos

Project artwork used to identify the projects in the homepage's Open Source section. All project names and logos belong to their respective owners; the section identifies Yunhao Zhou as a contributor.

- `sglang.png`: https://raw.githubusercontent.com/sgl-project/sglang/main/assets/logo.png
- `openevolve.png`: https://raw.githubusercontent.com/algorithmicsuperintelligence/openevolve/main/openevolve-logo.png

Downloaded on 2026-10-14. Original images are preserved without modification.

The homepage uses `sglang-official.svg`, the unmodified standalone logo from https://raw.githubusercontent.com/sgl-project/sglang/main/assets/logo_square.svg (downloaded on 2026-10-15). It preserves the official artwork without cropping or redrawing.

The homepage also uses `openevolve-symbol.svg`, a locally redrawn standalone symbol based on the original artwork. This transparent vector restores the upper-right red node obscured by the original wordmark's “O” and includes the full lower nodes. It is a local adaptation, not an official upstream SVG asset.

Project links are maintained in `index.html`; styles are in `static/css/main.css`. The compact contributor links use local images and do not require a GitHub API request when visitors load the page.
